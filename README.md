# Dyellen Morais | Micropigmentação e Design

Site de uma página de Dyellen Morais, especialista em micropigmentação e design de sobrancelhas, lábios e olhos, que também oferece o Curso VIP para formação de profissionais.

- **Cliente:** Dyellen Morais
- **Site publicado:** a definir (dyellen.imaguiar.com.br)
- **Instagram:** https://www.instagram.com/dyellenmorais/

## Tecnologias

HTML5, CSS3 e JavaScript puros, sem build. Imagens em WebP. SEO com meta description, canonical, Open Graph e dados estruturados JSON-LD (schema.org). Hospedagem prevista no GitHub Pages, com domínio em subdomínio de `imaguiar.com.br` (DNS na Cloudflare).

## Estrutura

```
index.html    página única (head com SEO e JSON-LD; corpo a preencher)
css/          estilos (style.css, a criar)
img/          imagens em WebP usadas no site
favicon.svg   ícone da aba (monograma "D", provisório)
CNAME         domínio personalizado do GitHub Pages
robots.txt    regras para buscadores
sitemap.xml   mapa do site
```

## Seções previstas

Início, sobre, serviços (sobrancelhas, lábios e olhos), resultados (3 fotos de antes e depois), Curso VIP, dúvidas frequentes e botão fixo de agendar (WhatsApp).
